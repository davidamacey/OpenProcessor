# CPU-installable subset sufficient to run `pytest tests/ -m 'not live'` on a
# GPU-less CI runner. Traced from `import src.main`'s real import graph plus
# every top-level (non-lazy) third-party import reachable from `tests/`.
#
# NOT included here: the engine-build toolchain (requirements-export.txt, image-only),
# pandas, matplotlib, seaborn,
# open-clip-torch, ftfy, timm, huggingface_hub (lazy-imported, and no
# not-live test calls them -- see requirements.txt for their call sites).
# faiss-cpu, umap-learn, hdbscan, imohash, onnxruntime, pycocotools and docker
# are lazy-imported by src/ but exercised by not-live tests, so they ARE here.
#
# torch/torchvision need the CPU wheel index, which pip requirements files
# cannot mix inline with the default PyPI index. Install this file in two
# passes:
#
#   pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
#   pip install -r requirements-test.txt
#
# (or use `pip install -r requirements-test.txt --extra-index-url
# https://download.pytorch.org/whl/cpu`, which also resolves torch/torchvision
# to CPU wheels because PyPI has no matching CUDA-free version for this pin).
