# Combine projects

Combine builds a new project from 1 to 8 existing ones. Sources are only read, and
class-name conflicts are resolved by a mapping you review first. Examples assume
`API=http://localhost:4603`. Combine routes are global, not project scoped.

## Concepts

- **Target.** A new project, `building` until the job succeeds (`active`) or fails
  (`failed`). Deleting a failed or unwanted target is a complete undo ([Projects](./projects.mdx)).
- **Source order is priority.** The first source wins a label conflict and donates the image
  of a duplicate.
- **Class mapping by name.** The target owns its class ids; nothing numbered crosses over.
  Each source class gets `map`, `create`, `skip` or `region`, as in
  [Dataset import](./dataset-import.mdx). The preview returns a `suggested_mapping`; a source
  class with data and no decision is `unmapped_class`.
- **Dedup.** `content_hash` (default) treats byte-identical images as one: copied once, boxes
  merged by IoU (`dedup_iou`, default 0.9). `none` keeps every image. Overlapping boxes of the
  same target class merge and the more trusted label survives (human, import, VLM, model);
  overlapping boxes of different classes keep the priority label and flag the item
  `combine_conflict` (with `combine_conflict_origins`).
- **Holdout.** `preserve_union` keeps the sources' frozen test splits as the target's;
  `recompute` draws a new split and warns that models trained on a source may have seen the
  new test images; `none` freezes none.
- **Clusters** are not copied; recluster afterwards (`next_steps` says so).
- **Provenance.** Items record `origin_project`, `origin_item_id`, `origin_image_id`.
- **Per source:** `include.label_states` is `all` or `validated_only`. `settings_from` names a
  source whose settings defaults, activations and prompt packs are copied.
- **Preview hash.** `preview_sha` covers the request and every source's state; starting
  requires it, so a source that changed in between is caught. A source with a running job
  cannot be combined.

## Routes

| Call | Purpose |
|---|---|
| `POST /curation/projects/combine/preview` | Dry run; writes nothing |
| `POST /curation/projects/combine` | Start the job (202) |
| `GET /curation/projects/combine/{job_id}` | Job status |
| `POST /curation/projects/combine/{job_id}/cancel`, `/resume` | Cancel a running job / resume an interrupted or cancelled one |

## Preview

```bash
curl -s -X POST "$API/curation/projects/combine/preview" \
  -H 'Content-Type: application/json' \
  -d '{"target": {"slug": "fleet", "display_name": "Fleet", "description": "Cars and trucks"},
       "sources": [{"project": "cars", "include": {"label_states": "all"}},
                   {"project": "trucks", "include": {"label_states": "validated_only"}}],
       "class_mapping": {}, "target_classes": null,
       "dedup": "content_hash", "dedup_iou": 0.9,
       "holdout": "preserve_union", "settings_from": "cars"}'
```

| Response field | Content |
|---|---|
| `ok`, `errors`, `warnings` | `ok` is false on errors; issues have `code`, `severity`, `project`, `message`, `detail` |
| `preview_sha` | Pass back when starting |
| `suggested_mapping` | Per source project, mapping rows (`dataset_class`, `action`, `class_id`, `new_class_name`, `new_class_group`) |
| `sources` | Per source: `images`, `items`, `labeled_items`, `holdout_images`, classes with `count` and `mapped_to` |
| `target` | `slug`, `slug_available`, resulting `classes`, and totals of the finished target: `projected_images`, `projected_items` (after merging; includes `unclassed_items`), `holdout_images` |
| `dedup` | `identical_images`, `merged_items`, `conflicts`, `conflict_samples` |
| `bytes` | `to_link`, `to_copy` |

Flow: preview, copy `suggested_mapping` into `class_mapping`, edit the decisions, preview
again until `ok` is true. `class_mapping` is keyed by source slug:

```json
{"class_mapping": {
  "cars":   [{"dataset_class": "car", "action": "create", "new_class_name": "vehicle"}],
  "trucks": [{"dataset_class": "truck", "action": "map", "new_class_name": "vehicle"},
             {"dataset_class": "wheel", "action": "region"}]}}
```

`target_classes` optionally fixes the order (and so the ids) of target classes; every name
must be created by a mapping row. The target registry is new, so `create` defines a class and
`map` names one by `new_class_name`; the same `create` name in two sources is one class.

Issue codes: `too_many_sources`, `duplicate_source`, `target_is_source`, `source_not_found`,
`source_not_ready`, `source_busy`, `slug_invalid`, `slug_taken`, `slug_retired`,
`shard_budget_exceeded`, `unmapped_class`, `mapping_target_invalid`, and warnings
`shard_budget_high`, `label_conflicts`, `holdout_recompute_contamination`,
`embedding_model_mismatch` (a source's vectors have another dimension than the target
encoder; they are not copied and the items are deferred for re-embedding) and
`region_profiles_differ`. Neither of the last two blocks the combine.

## Start, follow, cancel, resume

```bash
curl -s -X POST "$API/curation/projects/combine" -H 'Content-Type: application/json' \
  -d '{ ...the same body as the preview..., "expected_preview_sha": "<preview_sha>" }'
curl -s "$API/curation/projects/combine/JOB_ID"
curl -s -X POST "$API/curation/projects/combine/JOB_ID/cancel"
curl -s -X POST "$API/curation/projects/combine/JOB_ID/resume"
```

Start answers 202 `{"job_id": "...", "target": "fleet"}`; the target appears at once as
`building`. The job has `status`, `phase`, `target`, `sources`, `done`, `total` (images),
`report`, `next_steps`, `error`, `started_at`, `finished_at`.

`queued` and `running` are active; `completed` and `completed_with_errors` finished; `failed`
is terminal; `interrupted` (for example after a restart) and `cancelled` can be resumed.
Phases: `registry`, `images`, `holdout`, `done`. Progress is also published as
`combine.progress` on the global event stream. Resume re-checks every source and the preview
hash (a changed source ends in `preview_stale` and needs a new combine) and needs the target
still `building`. The job works in chunks of `OP_COMBINE_PAGE_SIZE` images (default 200), the
unit a resume redoes.

## Errors

| Status | `error` | When |
|---|---|---|
| 422 | `combine_invalid` | The start request has errors (`report` lists them) |
| 409 | `preview_stale` | A source changed since the preview |
| 404 | `combine_not_found`, `project_not_found` | Unknown job; a named project does not exist |
| 409 | `combine_not_resumable` | Cancel of a job that is not running, or resume of one that is running, finished, or whose target or sources are unusable |
| 409 | `shard_budget_exceeded` | The target would exceed the shard limit |
