# Test on a crop

Before activating a prompt pack or region profile, run it against stored crops and read the
result. Both test routes are dry runs: they write to no index, bump no revision and change no
item. They return what the production code path would have produced.

Examples assume `API=http://localhost:4603` and project `cars`.

## Concepts

- **Draft or saved.** The subject is a saved pack or profile (name and optional revision), a
  draft in the request body, or, with neither, the active one. Name and draft together are
  refused.
- **VLM source.** A pack test, and a profile test with `verify`, call a VLM: `vlm_name` (and
  optional `vlm_revision`), a `vlm_draft` endpoint body, or neither for the project's active
  endpoint. An endpoint outside the deployment sends a real crop to a third party and needs
  `acknowledge_external: true` ([VLM selection](./vlm-selection.mdx)).
- **Bounded.** At most 64 crop ids per pack test. Concurrent runs are capped per process (2 VLM,
  4 segmenter); over the cap is refused at once, not queued. A run stops after 60 seconds.
- **A parse failure is a result:** if the model answers but the reply does not parse, the call
  returns 200 with `parse_ok: false`.

| Call | Purpose |
|---|---|
| `POST /curation/projects/{project}/prompt_packs/test` | Run one VLM call of a pack over stored crops |
| `POST /curation/projects/{project}/region_profiles/test` | Run a profile's detector and segmenter legs over one stored crop |

## Test a prompt pack

```bash
curl -s -X POST "$API/curation/projects/cars/prompt_packs/test" \
  -H 'Content-Type: application/json' \
  -d '{"pack_name": "vehicle_wheel", "pack_revision": null, "draft": null,
       "call": "combined", "crop_ids": ["CROP_A", "CROP_B"],
       "use_region_box": "current", "class_names": null,
       "profile_name": "vehicle_wheel",
       "vlm_name": null, "vlm_revision": null, "vlm_draft": null,
       "acknowledge_external": false}'
```

| `call` | What it runs |
|---|---|
| `classify` | Classify items into the class names |
| `open_classify` | Classify, proposing a new class when none fits |
| `combined` | Classify and verify every stored box in one call (needs a region profile: the active one or `profile_name`) |
| `region_verify` | Verify one stored box per crop |
| `region_visible` | Ask whether a region is visible at all |
| `assist` | Classify and report item attributes (needs a pack that declares them, else `422 pack_declares_no_attributes`) |
| `attributes` | Report item attributes without classifying |

`use_region_box` (for `combined`): `current` draws every stored box as the numbered overlay,
`none` sends the crop bare. `class_names` overrides the registry class list; `profile_name`
selects the profile that gates region text (default the active one).

| Response field | Content |
|---|---|
| `call`, `pack`, `vlm` | What ran: `pack` is `{name, revision, draft}`; `vlm` is `{endpoint, model, name, revision, draft}` |
| `prompt` | The `system` and `user_text` sent |
| `raw_reply`, `reasoning` | The model's reply and its reasoning channel if any |
| `latency_ms`, `parse_ok`, `parse_error` | Round trip; whether the production parser accepted the reply |
| `results` | Per crop: `crop_id`, `box_id` (for `region_verify`), `parsed`, `preview_item`, `skipped` |
| `validation` | The pack's validation report against the profile |

`preview_item` is the item as the production write would leave it. It is null for
`region_visible`, `assist`, `attributes` (suggestions stored apart from the item; `parsed` is
the whole result) and for a skipped item (`skipped` gives the reason, such as `class_locked`).

## Test a region profile

```bash
curl -s -X POST "$API/curation/projects/cars/region_profiles/test" \
  -H 'Content-Type: application/json' \
  -d '{"crop_id": "CROP_A", "profile_name": "vehicle_wheel", "profile_revision": null,
       "draft": null, "segmenter_text_prompt": "wheel, tire", "verify": true,
       "prompt_pack_name": "vehicle_wheel", "prompt_pack_revision": null,
       "prompt_pack_draft": null, "vlm_name": null, "acknowledge_external": false}'
```

`segmenter_text_prompt` overrides the profile's prompt for this run (validated like any
prompt). With `verify` true, the combined VLM call also runs over the selected boxes, using
`prompt_pack_name`, a `prompt_pack_draft` or the active pack.

| Response field | Content |
|---|---|
| `profile`, `item_eligible` | `{name, revision, draft}`; true when the profile has no `parent_classes` or the crop's class is one |
| `legs` | Per leg (`detector`, `segmenter`): `status` (`ok`, `skipped`, `error`), `reason`, `elapsed_ms`, `candidates` |
| `preview_item`, `preview_basis` | The item as the worker would leave it; `selection_accepted` (no VLM) or `vlm_verdicts` |
| `verify` | The VLM call when `verify` was true |
| `validation` | The profile's validation report |

Each candidate is a full region box (`box_id` null, since ids are assigned on write) with
`bbox_norm`, `bbox_in_parent`, `score`, `detector`, `state`, text fields and `mask_polygon`,
plus `selected` and a `drop_reason` (`below_min_score`, `nms`, `over_max`). A failing leg is
reported on that leg with status 200; only when no leg ran is the answer 502.

## Errors

| Status | `error` | When |
|---|---|---|
| 404 | `crop_not_found`, `image_not_found` | Unknown crop id (`crop_ids` lists them); the image cannot be read |
| 409 | `no_active_profile`, `vlm_not_configured` | `combined` or a profile test with no profile active; no VLM available |
| 422 | `validation_failed` | No crop ids, or a saved subject and a draft together |
| 422 | `too_many_crop_ids`, `too_many_crops` | Over 64 ids (`limit` returned); more crops than one VLM request carries |
| 422 | `unknown_pack`, `unknown_revision`, `unknown_profile`, `unknown_vlm` | The named subject does not exist |
| 422 | `pack_invalid`, `profile_invalid` | A draft with errors (`report` lists them) |
| 422 | `vlm_external_not_acknowledged`, `no_box_to_verify`, `no_class_names` | External endpoint without acknowledgement; `region_verify` on a crop with no box; `classify` with an empty registry and no `class_names` |
| 429 | `test_busy` | All run slots taken; retry shortly |
| 502 | `vlm_transport_error`, `detector_error`, `segmenter_error` | VLM endpoint failed; no profile leg ran |
| 504 | `test_timeout` | Over 60 seconds |
