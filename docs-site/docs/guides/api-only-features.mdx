# Embedding spaces, presets and search (API)

Space management and the four presets are **API only (no Cropwright page)**: use `curl`, a script or the
interactive docs at `/docs`. The search routes are also used by the Clusters search box (below). Every route below sits under
`http://localhost:4603/curation/projects/<slug>` unless noted. `B` is that base URL.

## Embedding spaces

A space is one set of vectors for a target (`item`, `box`, `frame` or `item_text`) made by one
encoder version. A project always has a primary space; you can add candidates, compare them and
promote one.

```bash
curl -s "$B/embedding/spaces?target=item"                    # live and retired spaces
curl -s "$API/curation/embedding/models"                     # encoders this deployment can serve
curl -s -X POST "$B/embedding/spaces" -H 'content-type: application/json' \
  -H 'Idempotency-Key: try-1' \
  -d '{"model_key":"mobileclip2_s2","model_version":1,"target":"item"}'   # register and start the build
curl -s "$B/embedding/reindex-runs/RUN_ID"                   # build progress
curl -s -X POST "$B/embedding/spaces/SPACE_KEY/build?target=item" -H 'content-type: application/json' \
  -d '{"mode":"backfill","batch_size":64}'                   # restart a failed build or backfill
curl -s -X POST "$B/embedding/spaces/SPACE_KEY/promote?target=item" -H 'content-type: application/json' \
  -d '{"force":false}'                                       # make it the primary
curl -s -X POST "$B/embedding/spaces/SPACE_KEY/retire?target=item"   # retire a non-primary space
```

Promote answers `409 embedding_space_not_ready` or `embedding_evaluation_missing` until the build
is complete and evaluated; `force` waives only the missing evaluation. The primary space cannot be retired.
`POST .../reindex-runs/{run_id}/cancel` stops a build.

## Presets

Presets are revisioned config documents (same revision and `expected_revision` rules as
[Settings and config](./settings-and-config.mdx)). Each kind has the same six routes. For the
near-duplicate presets they are `GET /near_dup_profiles` (list), `GET /near_dup_profiles/{name}`,
`PUT /near_dup_profiles/{name}`, `DELETE /near_dup_profiles/{name}`,
`POST /near_dup_profiles/{name}/activate` and `GET /near_dup_profiles/active`; the other kinds swap the
collection name.

| Preset | Path | Scope | What it holds |
|---|---|---|---|
| Serving profile | `/curation/serving_profiles` (no project) | Deployment | Triton servers, which models stay resident, instances, image-prep and priorities |
| Cluster profile | `$B/cluster_profiles` | Project | Cluster method (`ivf`, `minibatch_kmeans`), embedding field, refresh rule, `activation`, `backend` |
| Assist-loop preset | `$B/assist_loop_presets` | Project | The cluster-sampled auto-label loop: gate, recursion, budget, `on_budget`, concurrency |
| Near-duplicate profile | `$B/near_dup_profiles` | Project | `dedup_cosine`, `leak_cosine`, `max_group_size`, `k` for the `image` and `item` levels |

```bash
curl -s "$B/near_dup_profiles/active"
curl -s -X PUT "$B/near_dup_profiles/strict" -H 'content-type: application/json' \
  -d '{"body":{"version":1,"item":{"dedup_cosine":0.97,"leak_cosine":0.93}},"description":"stricter items"}'
curl -s -X POST "$B/near_dup_profiles/strict/activate"
```

Bodies are validated strictly (unknown keys are refused). `leak_cosine` may not exceed
`dedup_cosine`. Read the field list from the schema in `/docs` before writing a body.

Near-duplicate runs, groups and decisions live next to the profile: `POST $B/near_duplicates/runs`,
`GET $B/near_duplicates/status`, `GET $B/near_duplicates/groups`, `POST $B/near_duplicates/decisions`
(undo with `DELETE .../decisions/{decision_id}`).

## Search

The Clusters search box calls these routes (text, by image, similar to an item, item or box
target, and a space picker). Call them directly for scripts. All three return `{items, total, page, page_size}` with a
`semantic_score`, and share the item filters of the Items grid plus `target` (`item` or `box`),
`space` and `fuse`.

```bash
curl -s "$B/search/text?q=red+car&page_size=20"
curl -s "$B/search/similar?crop_id=CROP_ID&exclude_self=true&page_size=20"
curl -s -X POST "$B/search/image?page_size=20" -F image=@query.jpg    # nothing is stored
curl -s "$B/search/text?q=red+car&space=SPACE_A&fuse=SPACE_B"         # reciprocal rank fusion
```

`search/image` also accepts `image_id` (a stored image) in place of the upload, and `box` for a
region of it. `search/similar` takes `box_id` to start from one region box.
