# Reprocess

Reprocess re-runs part of the pipeline on images or items that already exist: after a new
region profile or prompt pack is activated, after a detector is promoted, or to retry
failures. One route covers every case and is a dry run by default.

Examples assume `API=http://localhost:4603` and project `cars`.

## Concepts

- **Scopes.** One or more, run in this order:

  | Scope | Unit | What it regenerates |
  |---|---|---|
  | `detect` | image | Machine items from the ingest detectors; new proposals merge with existing items |
  | `open_vocab` | image | Items from the active open-vocabulary prompt set ([Open vocabulary](./open-vocabulary.mdx)) |
  | `region` | item | Machine region boxes |
  | `vlm` | item | The VLM's class answer: the VLM worker selects the item again |
  | `embed` | image | The PE vectors: item crop, whole frame, one per accepted or false-positive region box |

- **Lock rule.** Only machine output is regenerated. Human and imported labels and boxes are
  never written; a locked item with nothing to regenerate is `locked_skipped`. `detect`
  never writes, replaces or deletes a locked item, and a validated region set (including a
  human "no region visible") is not redone by `region`. `embed` covers locked items too,
  because vectors are derived.
- **Region mode.** `redetect` (default) removes unlocked machine boxes, keeps locked ones and
  queues the item as `pending_detection`. `reverify` turns unlocked `rejected` boxes back into
  `proposed` and queues `pending_verification`; a `detected` set cannot be re-verified.
- **Targets.** Exactly one of `crop_ids`, `image_ids` or `filter`, up to 5000 ids. An empty
  filter is refused.
- **Sync or job.** `region` and `vlm` run inside the call. `detect` and `embed` run inside the
  call for up to `OP_REPROCESS_SYNC_MAX` images (default 20) and as a background job above
  that (202 with `job`). One live job per project; the job is a PostgreSQL row, visible to
  every worker.

## Routes

| Call (under `/curation/projects/{project}`) | Purpose |
|---|---|
| `POST /reprocess` | Unified reprocess over ids or a filter |
| `GET /reprocess/jobs/{job_id}`, `POST /reprocess/jobs/{job_id}/cancel` | Job status / stop after the current chunk |
| `POST /crops/{crop_id}/reprocess`, `POST /images/{image_id}/reprocess` | One item or image; applies by default |

## Filter

At least one field must be set.

| Field | Meaning |
|---|---|
| `region_status` | Region statuses to select (list) |
| `missing_status` | Items with no region status. Exclusive with `region_status` |
| `detector`, `reason` | By the detector or rejection reason that produced the status |
| `profile_not`, `profile_revision_below` | Items not produced by that region profile, or by a revision below the number; together, not produced by exactly that profile at that revision |
| `include_detected` | Widen the region scope to `detected` items (needs a profile selector) |
| `missing_provenance` | Items with no recorded detector |
| `region_gate_skipped` | Items the region gate skipped (the segmenter was never asked); safe to re-run with `region` |
| `import_id` | Items from one dataset import |
| `source`, `class_id`, `dataset_split` | Narrow by source, class or split |
| `all_images` | Every stored image, including those with no item yet (image scopes only) |
| `open_vocab_status` | Images whose open-vocabulary state is `pending`, `done`, `skipped_gate` or `failed` (same restrictions as `all_images`) |

The `region` scope needs `region_status`, `missing_status` or a profile selector. A profile
selector alone selects `detection_failed`, `verify_rejected`, `no_region_box` and
`no_region_visible` items (and `detected` with `include_detected`). `targets.limit` with
`sample` (`random` with a `seed`, or `largest`) caps a filter for every scope; the dry run and
the apply act on the same capped items.

## Dry run, then apply

```bash
curl -s -X POST "$API/curation/projects/cars/reprocess" \
  -H 'Content-Type: application/json' \
  -d '{"targets": {"filter": {"profile_not": "vehicle_wheel", "include_detected": true}},
       "scopes": ["region"], "region_mode": "redetect", "dry_run": true}'
```

The response has `dry_run`, `scopes` and `job`. Each scope result has `selected`,
`locked_skipped`, `queued`, `not_found`, `failed`, `breakdown` (`detector`, `reason`,
`count`) and `detail`. Send the same body with `"dry_run": false` to run it. The active region
profile's impact route returns this request ready to post as `suggested_reprocess`
([Region profiles](./region-profiles.mdx)).

Other targets:

```bash
curl -s -X POST "$API/curation/projects/cars/reprocess" -H 'Content-Type: application/json' \
  -d '{"targets": {"image_ids": ["IMG_A", "IMG_B"]}, "scopes": ["detect", "embed"], "dry_run": false}'
curl -s -X POST "$API/curation/projects/cars/crops/CROP_ID/reprocess" -H 'Content-Type: application/json' \
  -d '{"scopes": ["region"], "region_mode": "redetect", "dry_run": false}'
curl -s -X POST "$API/curation/projects/cars/images/IMAGE_ID/reprocess" \
  -H 'Content-Type: application/json' -d '{"scopes": ["detect"]}'
```

The per-target routes also return `items` (the item or the image's items as written). A locked
set with nothing to regenerate answers `locked_skipped: 1`, `queued: 0`.

## Jobs

```bash
curl -s "$API/curation/projects/cars/reprocess/jobs/JOB_ID"
curl -s -X POST "$API/curation/projects/cars/reprocess/jobs/JOB_ID/cancel"
```

A job has `status` (`queued`, `running`, `completed`, `completed_with_errors`, `cancelled`,
`failed`), `scopes`, `images_total`, `images_done`, `images_failed`, `results` (per scope,
when finished), `error` and `poll_after_s` while active.

## Errors

| Status | `error` | When |
|---|---|---|
| 404 | `not_found`, `image_not_found` | Unknown crop or job; unknown image |
| 409 | `reprocess_busy` | A job is already running for this project |
| 422 | `reprocess_targets_invalid` | Not exactly one target form, empty or over-5000 id list, empty filter, region selection without a status or profile selector, `include_detected` without a profile selector, `detected` with `reverify`, or an unknown region status |
