# Projects

A project is an isolated dataset workspace with its own OpenSearch indexes, directories,
class registry, prompt packs, region profiles, keymap and active VLM endpoint. A request is
bound to one project by its URL, and the storage layer refuses any access that would reach
another project's indexes.

Examples assume `API=http://localhost:4603`.

## Concepts

- **Slug.** The project id in URLs: 2 to 32 characters, lowercase letters and digits with
  single hyphens, starting with a letter (`^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$`). Reserved:
  `all`, `combine`, `global`, `health`, `new`, `none`, `projects`, `settings`, `vlm`. A slug
  cannot be changed, and the slug of a deleted project is retired for good.
- **`default` project.** Created at bootstrap. It can be archived, never deleted.
- **Status.** `building`, `active`, `archived`, `deleting`, `deleted`, `failed`. Only
  `active` is writable; `archived` is readable and refuses writes; `building`, `deleting`
  and `failed` cannot be bound.
- **Revision.** Every lifecycle change bumps `revision`; PATCH, archive and unarchive need
  `expected_revision`, so two clients cannot overwrite each other.
- **Resources** are fixed at creation:

| Resource | Location |
|---|---|
| Indexes | `<OP_PROJECT_INDEX_PREFIX><slug>__<role>` (default prefix `op_prj_`) |
| Class registry, config documents, settings, jobs | PostgreSQL rows carrying the project id |
| Exports, bake-off eval sets | `<OP_PROJECTS_DATA_ROOT>/<slug>/exports/`, `.../bakeoff_eval/` |
| Uploads | `<OP_STATE_DIR>/projects/<slug>/uploads/` |
| MLflow experiment | `openprocessor-<slug>` |
| Promoted model prefix | `<slug>__` (`default` uses none) |

`GET /curation/projects/{project}` returns the resolved `resources`.

## Routes

| Call | Purpose |
|---|---|
| `GET`, `POST /curation/projects` | List (limits, shard capacity) / create |
| `GET`, `PATCH`, `DELETE /curation/projects/{project}` | Record with resources / display name and description / dry run or guarded delete |
| `POST .../{project}/archive`, `/unarchive` | Make read-only / writable again |
| `POST .../{project}/clone_settings` | Copy settings from another project |
| `GET`, `POST .../{project}/pause`; `POST .../{project}/resume` | Workers skip this project / clear it |

## List and create

```bash
curl -s "$API/curation/projects?include_archived=true"
curl -s -X POST "$API/curation/projects" -H 'Content-Type: application/json' \
  -d '{"slug": "cars", "display_name": "Cars and wheels", "description": "Public car photos",
       "clone_settings_from": null, "clone_axes": null}'
```

The list has `projects` (each with `slug`, `status`, `revision`, `is_default`, `counts`,
`writable`, `archivable`, `deletable`, `paused`, ...), `default_slug`, `limits` and
`capacity` (the OpenSearch shard budget: `ok`, `warn`, `blocked`).

Create answers 201 with `project`, `warnings` and `keymap_clone_conflicts`; a
`shard_budget_high` warning means the cluster is near its shard limit. It writes a
`building` record, creates indexes and directories, optionally clones settings, then flips to
`active`; a failure midway leaves the record `failed`, never partly active.

`clone_settings_from` names an `active` or `archived` project. `clone_axes` limits what is
copied: `settings_defaults`, `classes`, `activations`, `keymap`, `prompt_packs`,
`vlm_activation` (null or empty = all). See [Settings and configuration](./settings-and-config.mdx).

## Edit, archive, unarchive

```bash
curl -s -X PATCH "$API/curation/projects/cars" -H 'Content-Type: application/json' \
  -d '{"expected_revision": 3, "display_name": "Cars", "description": "Public car photos"}'
curl -s -X POST "$API/curation/projects/cars/archive" \
  -H 'Content-Type: application/json' -d '{"expected_revision": 4}'
curl -s -X POST "$API/curation/projects/cars/unarchive" \
  -H 'Content-Type: application/json' -d '{"expected_revision": 5}'
```

Archive is refused while the project has running jobs and for the last active project.

## Delete

Dry run first; it writes nothing:

```bash
curl -s -X DELETE "$API/curation/projects/cars?dry_run=true"
curl -s -X DELETE "$API/curation/projects/cars?confirm=cars"
```

The dry run lists `indexes`, `dirs`, `mlflow_experiment`, `promoted_models`, `running_jobs`,
`referenced_by` (other projects using its shared models) and `blocking` / `blocking_detail`.
The real delete needs `confirm` equal to the slug and answers 202 with status `deleting`;
removal runs in the background. Poll `GET /curation/projects/{project}` until 404, or follow
`project.deleted` on `GET /curation/events`. A failed finish leaves the record `deleting`;
repeat the call to retry. Recreating a deleted slug gives `slug_retired`, so scripts need a
fresh slug each run. `force=true` skips only the shared-model refusal, not the busy check, the
last-active check or `default` protection.

## Pause and resume

```bash
curl -s -X POST "$API/curation/projects/cars/pause"
curl -s "$API/curation/projects/cars/pause"
curl -s -X POST "$API/curation/projects/cars/resume"
```

A paused project is skipped at every worker's next cycle. Both are idempotent; the response
has `paused`, `paused_by` and `reason`.

## Errors

Body shape: `{"detail": {"error": "<code>", "message": "...", ...}}`.

| Status | `error` | When |
|---|---|---|
| 404 | `project_not_found` | Unknown or deleted slug |
| 409 | `project_building`, `project_deleting`, `project_failed` | State cannot be bound |
| 409 | `project_archived`, `project_read_only` | Write to an archived project; registry cannot be confirmed fresh |
| 409 | `slug_taken`, `slug_retired` | Create with a used or retired slug |
| 409 | `revision_conflict` | Stale `expected_revision` (`current_revision` returned) |
| 409 | `invalid_transition` | For example archiving a project that is not `active` |
| 409 | `project_busy` | Running jobs (`jobs` lists them); a worker finishing its last batch clears within about 15 seconds |
| 409 | `last_active_project`, `project_protected` | Would leave no active project; delete of `default` |
| 409 | `in_use` | Delete while another project depends on a shared model |
| 409 | `shard_budget_exceeded` | Create blocked (`capacity` returned) |
| 409 | `clone_source_not_ready`, `target_not_empty` | Clone source not `active`/`archived`; clone into a project with data |
| 422 | `slug_invalid`, `confirm_mismatch`, `combine_invalid` | Bad slug; `confirm` is not the slug; unknown clone axis or clone into itself |

There is no project subcommand in the `openprocessor` CLI; use the API. Per-project
environment values are in [Basic configuration](../configuration/basic.mdx).
