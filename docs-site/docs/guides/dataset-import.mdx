# Dataset import

Bring an already-labeled dataset into a project. Classes are mapped by name, never by
index; a dataset's class order is not trusted. Examples assume `API=http://localhost:4603`
and project `cars`.

## Formats

`source.format` is `auto` (default) or one of:

| Format | Layout |
|---|---|
| `yolo` | `data.yaml` (or `classes.txt`, `obj.names`, `names.txt`) plus `images/` and `labels/` per split. Rows with more than five columns (polygon, oriented box) import as their bounding box. |
| `coco` | A directory with `images/` and `annotations/*.json` (pass the directory, not `images/` or a JSON file). Segmentation-only files are not read. |
| `voc` | `Annotations/*.xml`, images in `JPEGImages/` (else `images/`), optional `ImageSets/Main/*.txt` splits. Objects marked `difficult` are skipped. |
| `openimages` | `class-descriptions-boxable.csv`, `*-annotations-bbox.csv` (split from the file name), images named `<ImageID>.<ext>`. Group boxes skipped; images with no box row are not imported. |
| `cvat`, `labelstudio`, `kitti`, `createml`, `labelme` | CVAT "for images 1.1" `annotations.xml`; Label Studio full JSON (not `JSON_MIN`) with `rectanglelabels`; KITTI `label_2/`; CreateML; LabelMe `rectangle` shapes. Non-box shapes are skipped (`shape_not_box_skipped`). CVAT video tracks are not read. |
| `openprocessor_export` | An export written by this system, re-importable where it was written. |

`auto` tries, first match wins: export, YOLO with a `data.yaml`, COCO, VOC, Open Images,
CVAT, Label Studio, CreateML, LabelMe, KITTI, then YOLO from an `images/` directory. A
`data.yaml` always wins. Force a format with `source.format`. An image with no objects is a
verified negative in the formats that can say so. A reference that leaves the dataset (`..`,
an absolute path, a link out, a URL) is never followed (`image_file_missing`). A declared
image size that disagrees with the image skips it (`image_size_mismatch`).

## How an import works

- **Allowed paths.** `source.path` is absolute and, after symlinks, under an image source
  root (`OP_SOURCE_ROOT`, `OP_SOURCE_PATH_ALIASES`), the project's upload root or export
  root. Everything the dataset names must stay inside it. There is no `root` request field.
- **Preview, then import.** A preview writes nothing and returns the format, totals,
  splits, a decision row per class, issues and an `import_key`. The import re-scans and is
  authoritative. It runs as a background job (202) in persisted chunks; one import per
  project at a time.
- **Class mapping.** Each class with boxes needs one decision: `map` to an existing
  `class_id`, `create` (`new_class_name`, optional `new_class_group`), `skip` (frames stay
  unlabeled) or `region` (a region of its parent item; needs an active region profile).
  The preview suggests a decision with a `match` kind. `accept_suggestions: true` fills only
  the safe matches (same class, exact name, case or spacing difference, region class);
  synonym, merged and create suggestions need an explicit decision.
  `index_would_have_mapped_to` shows what index-based mapping would have got wrong.
- **Idempotent.** `import_key` hashes the source, mapping and the options that change what
  is written. Repeating a completed import returns the finished job with `reused: true`.
- **Human edits win.** A label or box a person set meanwhile is not overwritten
  (`label_conflicts_locked`).
- **Undo** restores class snapshots and box history, deletes the items and images the
  import created and deprecates classes it created. Items a person edited or another import
  shares are kept.

## Routes

All under `/curation/projects/{project}/datasets`:

| Call | Purpose |
|---|---|
| `POST /uploads` | Upload a dataset archive |
| `GET /formats` | Formats, issue catalog, upload limits |
| `POST /preview` | Preview; writes nothing |
| `POST`/`GET /imports` | Start / list (`page`, `page_size`, `status`) |
| `GET /imports/{import_id}` | Status and report |
| `GET /imports/{import_id}/entries`, `/issues` | Per-image rows (filters `split`, `label_state`, `status`) / issues with samples |
| `POST /imports/{import_id}/cancel`, `/resume`, `/undo` | Stop; continue an interrupted, failed or cancelled import (re-checks the source); dry run or real undo |

## Upload an archive

If the dataset is not under a source root, upload one `.zip`, `.tar` or `.tar.gz` (multipart
field `file`):

```bash
curl -s -X POST "$API/curation/projects/cars/datasets/uploads" -F 'file=@my_dataset.zip'
```

The 201 answer has `upload_id`, `dataset_path`, `files`, `bytes`; use `dataset_path` as
`source.path`. Extraction accepts only regular files and directories (a symlink or device
fails the archive) and caps member count, bytes and compression ratio.
`OP_DATASET_UPLOAD_MAX_BYTES` (default 2 GiB), `OP_DATASET_UPLOAD_MAX_FILES` and
`OP_DATASET_UPLOAD_TTL_H` set the limits and the sweep; `GET .../formats` returns them as
`upload_limits`.

## Preview

```bash
curl -s -X POST "$API/curation/projects/cars/datasets/preview" \
  -H 'Content-Type: application/json' \
  -d '{"source": {"path": "/data/source/my_dataset", "format": "auto"},
       "mapping": [], "accept_suggestions": false,
       "options": {"processing": "none", "label_trust": "validated"}}'
```

The response has `format`, `root`, `source_sha`, `import_key`, `splits`, `totals`,
`classes` (per class: `boxes`, `images`, `suggestion`, `resolved`), `region`, `issues`,
`blocking`, `force_allowed` and `estimate`. For COCO with explicit files add
`"coco_annotations": [{"path": "annotations/instances_train.json", "images_dir": "images/train", "split": "train"}]`
to `source`.

## Options

| Option | Default | Meaning |
|---|---|---|
| `processing` | `none` | `propose` also runs the detector to find what the labels missed |
| `label_trust` | `validated` | `validated`: imported labels are ground truth. `suggestion`: boxes are proposals a reviewer confirms |
| `parents` | `auto` | For region classes: parent items from the labels, or run the detector (`detect`) |
| `freeze_test_split` | null | Freeze the dataset's test split as the held-out set (null is false, except for an export that was itself frozen) |
| `missing_label` | `unlabeled` | An image with no label file is `unlabeled` or `negative` |
| `region_negatives` | true | Parent items with no region box on labeled frames are recorded as having none |
| `region_containment` | 0.9 | 0.5 to 1.0; threshold for assigning a region box to a parent |
| `name`, `source_tag` | `dataset_import` | Job label and tag on imported items (1 to 120 characters) |
| `force` | false | Start despite bypassable blocking issues |

`name`, `source_tag` and `force` do not change `import_key`.

## Start

```bash
curl -s -X POST "$API/curation/projects/cars/datasets/imports" \
  -H 'Content-Type: application/json' \
  -d '{"source": {"path": "/data/source/my_dataset"},
       "mapping": [
         {"dataset_class": "car", "action": "map", "class_id": 0},
         {"dataset_class": "wheel", "action": "region"},
         {"dataset_class": "bus", "action": "create", "new_class_name": "bus", "new_class_group": null},
         {"dataset_class": "other", "action": "skip"}],
       "options": {"name": "my_dataset", "freeze_test_split": true},
       "expected_import_key": "<import_key from the preview>"}'
```

`expected_import_key` makes the call 409 `dataset_changed` if the dataset or mapping changed
since the preview. The answer is 202 with the job; a repeat of a completed import is 200 with
`reused: true`.

## Follow and control

```bash
curl -s "$API/curation/projects/cars/datasets/imports/IMPORT_ID"
curl -s "$API/curation/projects/cars/datasets/imports/IMPORT_ID/entries?status=failed&page_size=100"
curl -s "$API/curation/projects/cars/datasets/imports/IMPORT_ID/issues?code=label_file_missing"
curl -s -X POST "$API/curation/projects/cars/datasets/imports/IMPORT_ID/cancel"
curl -s -X POST "$API/curation/projects/cars/datasets/imports/IMPORT_ID/resume"
```

`status` is one of `queued`, `running`, `paused_backpressure`, `completed`,
`completed_with_errors`, `failed`, `cancelled`, `interrupted`, `undoing`, `undone`. The job
also has `progress` (with `eta_s`), `poll_after_s`, `report`, `issues_summary`, `next_steps`
and `error`. `paused_backpressure` means the region worker queue is full
(`OP_DATASET_IMPORT_MAX_PENDING`); the import continues by itself. `report` counts images,
items, labels and boxes created, updated, reused, failed or skipped, `negatives`,
`unlabeled`, `holdout_frozen`, `label_conflicts_locked` and `disagreements` (dataset label
differs from the existing one). A dataset updated over an earlier import removes items the
new version lacks, except those a person or a held-out freeze touched.

## Undo

A dry run is the default and writes nothing:

```bash
curl -s -X POST "$API/curation/projects/cars/datasets/imports/IMPORT_ID/undo" \
  -H 'Content-Type: application/json' \
  -d '{"dry_run": true, "remove_images": true, "deprecate_created_classes": true}'
```

The report counts items deleted, restored and kept (human-edited or shared), boxes removed,
images deleted or kept and classes deprecated. With `"dry_run": false` the undo runs in the
background; poll until `undone`.

## Issues

`GET .../datasets/formats` serves the catalog (`code`, `severity`, `blocking`, `bypassable`).
Blocking issues refuse the import with 422 `import_blocked`; `force` bypasses only
`test_split_changed` (the frozen test split no longer matches `TEST_FROZEN.json`).

| Blocking code | Meaning |
|---|---|
| `dataset_path_not_allowed`, `format_undetected` | Path outside the allowed roots, or no layout found |
| `data_yaml_invalid`, `data_yaml_names_missing`, `yolo_names_file_invalid`, `coco_json_invalid`, `coco_category_duplicate_name`, `openimages_csv_invalid`, `openimages_class_duplicate_name` | Unreadable or ambiguous class list |
| `dataset_too_large`, `dataset_file_too_large` | Over the preview file limit or a size cap |
| `class_unmapped`, `class_mapping_conflict`, `class_name_exists`, `class_mapped_to_deprecated` | Mapping problems |
| `region_profile_required` | A `region` mapping with no active region profile |
| `names_mismatch`, `manifest_unreadable` | An export that does not match its registry |

Common warnings: `label_file_missing`, `label_row_malformed`, `label_class_out_of_range`,
`label_coords_out_of_range`, `label_box_degenerate`, `image_unreadable`,
`image_size_mismatch`, `coco_bbox_out_of_image`, `voc_xml_invalid`,
`openimages_class_unknown`, `image_file_missing`, `labelstudio_task_skipped`,
`labelme_json_invalid`, `shape_not_box_skipped`.

## Errors

| Status | `error` | When |
|---|---|---|
| 404 | `import_not_found` | Unknown `import_id` |
| 409 | `dataset_changed` | `expected_import_key` no longer matches |
| 409 | `import_busy` | Another import or undo is running in the project |
| 409 | `import_resumable` | An interrupted import of this dataset exists; resume it |
| 409 | `import_not_resumable`, `import_not_undoable` | Wrong state for resume / undo of a running import |
| 413 | `upload_too_large` | Archive over the limit |
| 422 | `archive_invalid` | Not a readable, safe archive |
| 422 | `class_mapping_incomplete` | A class with boxes has no mapping (`unmapped` lists them) |
| 422 | `class_mapping_invalid` | Bad mapping or a class could not be created |
| 422 | `import_blocked` | Blocking issues (`issues` lists them) |
| 503 | `config_store_unavailable` | The encoder or ingest is not ready |
